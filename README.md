📌 Loan Approval Analysis Dashboard
🔍 Overview
This project analyzes loan approval data to identify key factors influencing approval decisions. The workflow includes data cleaning, exploratory data analysis, and dashboard creation using Power BI.

⚙️ Tools Used
Python (Pandas, Matplotlib, Seaborn)

Power BI (dashboard & visualization)

📊 Dashboard Preview

📈 Key Insights
Credit history is the strongest factor influencing loan approval

Income alone does not guarantee approval

Higher loan amounts slightly increase rejection likelihood

🧠 Process
Data cleaning and preprocessing using Python

Handling missing values using median and mode

Exploratory analysis to identify patterns

Building interactive Power BI dashboard with KPIs and filters

📁 Files Included
cleaned_loan_data.csv – cleaned dataset

loan_analysis.ipynb – Python analysis

loan_dashboard.pbix – Power BI dashboard
